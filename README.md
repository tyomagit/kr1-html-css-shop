# Учебный интернет-магазин ShopProject

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».
Тема: «HTML и CSS: разработка многостраничного сайта».

Автор: **Мацейко Артём Викторович**, группа **ЭФБО-02-25**.

Сайт состоит из пяти страниц. Пользователь может открыть каталог, сравнить
три учебных товара, посмотреть характеристики и проверить форму заявки
на отдельной странице или в модальном окне. Основной код — HTML и CSS без
фреймворков; небольшой JavaScript управляет диалогом и проверкой формы.

## Ссылки

- Репозиторий для сдачи в СДО: https://github.com/tyomagit/kr1-html-css-shop
- GitHub Pages: https://tyomagit.github.io/kr1-html-css-shop/

## Просмотр проекта

Откройте `index.html` в браузере или запустите проект через расширение Live Server
в VS Code. Установка зависимостей и сборка не требуются. Все изображения и стили
локальные, внешних шрифтов и CDN нет.

## БЭМ-структура проекта

| Блок | Назначение |
| --- | --- |
| `site-header`, `site-nav`, `site-footer` | Шапка, общее меню, подвал |
| `breadcrumbs`, `hero`, `section` | Путь по сайту, первый экран, разделы |
| `products-grid`, `product-card` | Сетка и независимая карточка |
| `catalog-layout`, `catalog-filters` | Макет каталога и статические фильтры |
| `product-details`, `product-table` | Описание товара и характеристики |
| `order-form`, `order-dialog` | Самостоятельная форма и модальное окно |
| `button`, `success-message`, `back-to-top` | Кнопки, результат проверки, переход наверх |
| `faq`, `contact-info` | Частые вопросы и контакты |

Элемент записывается как `product-card__title`, модификатор —
`product-card--featured` или `site-nav__link--active`. Модификатор применяется
вместе с базовым классом. Форма и диалог разделены: одна и та же структура
`order-form` используется внутри диалога и на странице `order.html`.

### Аудит классов в практике 7

| До рефакторинга | После рефакторинга |
| --- | --- |
| `.site-logo` | `.site-header__logo` |
| `.site-header` у внутреннего контейнера | `.site-header__inner` |
| `.site-nav__list a` | `.site-nav__link` |
| `.breadcrumbs a`, `.breadcrumbs span` | `.breadcrumbs__link`, `.breadcrumbs__current` |
| `.form-field`, `.form-actions` | `.order-form__field`, `.order-form__actions` |
| `.form-field input` | `.order-form__input` |
| `.filters-form fieldset` | `.catalog-filters__group` |
| `.catalog-products` | `.catalog-layout__products` |
| `.product-card .button` | `.product-card__button` |

Основные компоненты оформляются прямыми классами. Селекторов по `id` и inline-стилей
нет. `id` используются для якорей, `label`, доступных названий и JavaScript.

## CSS и позиционирование

- В `:root` находятся цвета, отступы, скругления и ширина контейнера.
- Навигация и карточка используют Flexbox; сетки товаров, каталога и описания — Grid.
- `product-card` задаёт `position: relative`, бейдж — `position: absolute`.
- Боковой фильтр использует `position: sticky`.
- Кнопка «Наверх» и сообщение о результате используют `position: fixed` и `z-index`.
- Есть состояния `:hover`, `:focus-visible`, `:disabled`, активная ссылка меню и ошибки формы.
- Медиазапросы и полноценная мобильная адаптация оставлены для КР №3.

## Самостоятельные доработки

- Три подробных описания на `product.html` и общая таблица сравнения.
  Каждая карточка ведёт якорем к соответствующей модели.
- Варианты карточек «Хит» и «Скидка», бейджи и более подробные описания.
- Быстрая заявка доступна с главной, каталога и страницы товара. Товар и тема
  подставляются в видимые поля диалога автоматически.
- Отдельная страница заявки и прямой переход к ней из контактов и общего меню.
- Нативный FAQ на `details`/`summary`, работающий без JavaScript.
- `aria-current`, явные подписи полей, подсказка формата телефона, сообщения
  `role="status"`, исправление состояния ошибки при вводе и сбросе формы.

## Ограничения учебного проекта

- Backend, оплата, хранение заявок и отправка данных отсутствуют. После проверки
  появляется честное сообщение: «Проверка пройдена. Это учебная форма: данные не отправлены».
- Каталог и фильтры статические, как требуется для КР №1. Кнопка «Применить»
  отключена, рядом указано, что отбор пока недоступен.
- Названия, характеристики, изображения и контактные данные демонстрационные.
- Bootstrap не подключён. КР №2 — отдельная реализация в отдельном репозитории
  `kr2-bootstrap-shop`; документ практики 8 только задаёт эту следующую работу.

## Проверка перед сдачей

1. Открыть все пять страниц и проверить одинаковое меню, уникальные заголовки и хлебные крошки.
2. Перейти к `index.html#advantages`, `index.html#popular`, `index.html#contacts`.
3. В каталоге открыть «Подробнее» у каждой модели: ссылка должна вести к её описанию.
4. Проверить изображения, таблицу, бейджи, Grid и закреплённую кнопку «Наверх».
5. Нажать «Заказать» и проверить автоматически выбранный товар, закрытие кнопкой и Escape.
6. На `order.html` отправить пустую форму: браузер должен показать ошибку.
7. Проверить ошибочный e-mail, формат телефона и обязательное согласие.
8. Заполнить корректно: товар, имя от двух символов, e-mail, телефон вида
   `+7 (900) 123-45-67`, тему и согласие; проверить сообщение и сброс формы.
9. Открыть GitHub Pages после публикации, повторить переходы и проверить загрузку стилей.
