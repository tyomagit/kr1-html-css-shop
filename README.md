# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `images/product-placeholder.svg` — простая иллюстрация карточек товаров;
- `js/main.js` — открытие модального окна и проверка формы;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Раскладка и позиционирование

- Шапка и навигация расположены с помощью Flexbox, карточки товаров — с помощью CSS Grid.
- В карточках используются классы `.product-card`, `.product-card__img`, `.product-card__title`, `.product-card__price` и `.product-card__button`.
- Карточка имеет `position: relative`, цена — `position: absolute`, сообщение об успешной отправке — `position: fixed`.

## Навигация между страницами

- Одинаковое меню связывает `index.html`, `catalog.html` и `contacts.html`.
- Ссылки `index.html#advantages`, `index.html#popular` и `index.html#contacts` ведут к разделам главной страницы с любой страницы сайта.
- Хлебные крошки на внутренних страницах показывают путь от главной страницы до текущей.
- `scroll-behavior: smooth` делает прокрутку плавной, а `:target` выделяет выбранный раздел пунктирной рамкой.
