# Учебный интернет-магазин ShopProject

## Описание проекта

ShopProject — многостраничный сайт учебного интернет-магазина. На сайте можно
посмотреть шесть моделей товаров, сравнить комплектации и цены, прочитать примеры
отзывов и заполнить форму заявки. Проект выполнен на HTML и CSS без CSS-фреймворков.
JavaScript используется для открытия диалога и проверки формы.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализованы пять обязательных страниц, семантическая разметка, единая
навигация, якорные ссылки, карточки товаров, таблица, форма и модальное окно.
Для оформления используются CSS-переменные, Flexbox, Grid и методология БЭМ.

## Просмотр проекта

1. Скачайте репозиторий или откройте его локальную папку.
2. Откройте `index.html` в браузере. Также можно открыть папку в VS Code
   и запустить страницу через расширение Live Server.
3. Используйте общее меню для переходов между страницами.

Установка зависимостей и сборка не требуются. Стили, скрипт и изображение находятся
внутри проекта; внешние библиотеки и CDN не используются.

## Страницы и навигация

| Страница | Содержание |
| --- | --- |
| `index.html` | Первый экран, преимущества, популярные товары, отзывы и частые вопросы |
| `catalog.html` | Шесть карточек товаров, цены и боковой макет фильтров |
| `product.html` | Подробные описания моделей, наличие, цены и сравнение характеристик |
| `order.html` | Форма выбора товара или консультации и ввода контактных данных |
| `contacts.html` | Демонстрационные контакты и ссылка на форму заявки |

На всех страницах используется одинаковое меню. Текущая страница выделена классом
`site-nav__link--active` и атрибутом `aria-current="page"`. Внутренние страницы
содержат хлебные крошки.

Ссылки `index.html#advantages`, `index.html#popular`, `index.html#reviews`
и `index.html#contacts` ведут к разделам главной. Ссылка «Подробнее» в карточке
ведёт к соответствующей модели: от `product.html#product-1` до `product.html#product-6`.
Кнопка «Наверх» возвращает к шапке текущей страницы.

## БЭМ-структура проекта

| Блок | Назначение |
| --- | --- |
| `site-header`, `site-nav`, `site-footer` | Шапка, основная навигация и подвал |
| `hero`, `section`, `breadcrumbs` | Первый экран, разделы и хлебные крошки |
| `products-grid`, `product-card` | Сетка товаров и независимая карточка |
| `catalog-layout`, `catalog-filters` | Макет каталога и боковая панель фильтров |
| `product-details`, `product-table` | Описание товара и таблица характеристик |
| `order-form`, `order-dialog` | Форма заявки и модальное окно |
| `button`, `success-message`, `back-to-top` | Кнопки, результат проверки формы и ссылка наверх |
| `faq`, `contact-info` | Частые вопросы и контактная информация |
| `reviews`, `review-card` | Раздел отзывов и отдельная карточка отзыва |

Элемент обозначает часть блока: `product-card__title`, `order-form__input`,
`review-card__author`. Модификатор задаёт вариант или состояние:
`product-card--featured`, `button--secondary`, `order-form__input--error`.
Модификатор используется вместе с базовым классом.

Основные компоненты оформляются прямыми классами. Стили по `id` и inline-стили
не используются. `id` нужны для якорей, подписей полей и поиска элементов в JavaScript.

## CSS и расположение элементов

- В `:root` заданы общие цвета, отступы, скругления и ширина контейнера.
- Flexbox используется для меню и вертикальной структуры карточек товаров и отзывов.
- Grid используется для товаров, макета каталога, описаний моделей и списка отзывов.
- Карточка товара имеет `position: relative`, её бейдж — `position: absolute`.
- Фильтры каталога используют `position: sticky`.
- Кнопка «Наверх» и сообщение о результате формы используют `position: fixed` и `z-index`.
- Оформлены состояния `:hover`, `:focus-visible`, `:disabled`, активные ссылки и ошибки формы.

## Работа формы и диалога

Форма содержит выбор товара или консультации, имя, e-mail, телефон, дату связи,
тему, комментарий и согласие на обработку данных. Обязательны товар или консультация,
имя, e-mail, телефон, тема и согласие. Имя должно содержать минимум два символа;
телефон вводится в формате `+7 (900) 123-45-67`.

При нажатии кнопки заказа скрипт читает `data-product`, выбирает соответствующий
товар и тему «Заказ товара», затем вызывает `showModal()`. Диалог закрывается
кнопкой «Закрыть» или клавишей Escape. Такая же форма доступна на странице заявки.

При отправке скрипт отменяет переход на сервер через `preventDefault()`.
`checkValidity()` проверяет ограничения полей, а `reportValidity()` показывает
подсказку браузера. Неверные поля получают `aria-invalid` и БЭМ-модификатор ошибки.
При исправлении значения или очистке формы состояние ошибки обновляется.
После корректного заполнения форма сбрасывается и появляется сообщение о результате.

## Блок отзывов

Раздел `reviews` расположен на главной после популярных товаров. Каждый отзыв —
самостоятельный `article` с классом `review-card`. Содержимое оформлено через
`blockquote`; оценка имеет текстовое описание для программ чтения с экрана.
Ссылки в карточках ведут к описаниям соответствующих моделей.

Перейти к разделу можно кнопкой «Читать отзывы» на первом экране и ссылкой
«Отзывы» в подвале любой страницы. Имена и тексты вымышлены и отмечены на сайте
как учебные примеры. Добавление и хранение новых отзывов не реализованы.

## Ограничения проекта

- Форма проверяет данные только в браузере. Backend, отправка заявок, оплата и хранение данных отсутствуют.
- Фильтры каталога — статический макет. Кнопка применения отключена, рядом есть пояснение.
- Товары, характеристики, контактные данные и отзывы демонстрационные.
- Полная адаптация под мобильные устройства оставлена для последующей работы.
